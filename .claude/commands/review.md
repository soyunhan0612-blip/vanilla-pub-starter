## 체크리스트

1. **Tier 0 단독 동작**: npm 패키지 없이도 동작하는가? `node_modules/` 를 전제한 코드가 들어가지 않았는가?
2. **레이어 규칙**: `assets/js/util/` 이 `document`·`window` 를 참조하지 않는가? 역방향 의존이 없는가?
3. **토큰 단일 지점**: 컴포넌트 SCSS에 색·크기 리터럴이 없는가? 토큰이 CSS 변수로 출력되는가?
4. **단일 소스**: 컴포넌트 마크업이 `assets/components/` 에만 있는가? 페이지에 복붙되지 않았는가?
5. **PC/MO 공유**: `common/` 에 PC 전용 분기가 들어가지 않았는가? 양쪽 모두 반영되었는가?
6. **시맨틱 마크업**: 랜드마크(main/header/footer/nav) 사용, heading 순서, 폼 레이블 연결
7. **접근성 (WCAG 2.1 AA)**: 색상 대비 4.5:1, 키보드 조작, 포커스 표시, `aria-*` 적절성
8. **이미지**: `alt`, `loading`, `width`/`height` 가 있는가? `<picture>` + WebP 를 쓰는가?
9. **크로스브라우징**: iOS Safari 대응(입력 16px, safe-area, `100dvh`)이 필요한 곳에 적용되었는가?
10. **@component 주석**: 새 컴포넌트에 주석이 있는가? (없으면 카탈로그·스니펫에서 누락됨)
11. **테스트**: `util/` 에 추가된 함수에 테스트가 있는가?
12. **검증 통과**: `node tools/check.js` 가 통과하는가?
