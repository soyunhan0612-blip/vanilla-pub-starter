# PRD: 이커머스 퍼블리싱 보일러플레이트

## 목표

이커머스 쇼핑몰 퍼블리싱을 시작할 때 바로 쓸 수 있는 재사용 뼈대를 만든다. 현업이 폐쇄망이고 Claude를 쓸 수 없으므로, **사람이 손으로 이어받아 작업할 수 있는 상태**로 완성한다.

## 사용자

퍼블리셔 본인(현업에서 손으로 페이지를 채움) → 개발사(마크업을 서버 템플릿으로 이관)

## 산출물

| 구분 | 내용 |
|---|---|
| 디자인 토큰 | 색·타이포·간격·레이아웃. CSS 변수로 출력. 시안 수령 시 **값만 교체** |
| 공통 컴포넌트 | 범용 11종 + 이커머스 8종 = 19종. 마크업 fragment + SCSS + JS 바인딩 |
| 레이아웃 스켈레톤 | 7페이지 × PC/MO = 14장. **영역 구조와 그리드만**, 스타일은 비움 |
| 도구 | 의존성 0 서버·빌드·검증 스크립트 |
| 문서 | 컨벤션, 시안 검토 체크리스트, QA 체크리스트, 크로스브라우징 대응표 |
| 가이드 | `guide.html` — 컴포넌트 카탈로그 + 레이아웃 미리보기 + axe. 자동 생성 |

## 대상 페이지 (레이아웃 스켈레톤)

메인 / 카테고리 / 상품리스트 / 상품상세 / 장바구니 / 주문결제 / 마이페이지

## MVP 제외 사항

- **완성된 페이지 디자인** — 시안이 없으므로 스타일을 입히지 않는다. 영역 구조까지만
- **이커머스 도메인 로직** — 실제 데이터 연동, 결제, 상태 관리. 연동 지점만 `data-bind` 로 표시
- **백엔드·서버** — UA 분기 판별은 서버 몫. 참조 구현만 제공
- **번들러 의존 기능** — Vite는 있으면 쓰는 선택 레이어. 없어도 전부 동작해야 한다

## 디자인 방향

시안 부재 상태이므로 아래를 **플레이스홀더 기준**으로 삼는다. Figma 수령 시 `assets/scss/tokens/` 값만 교체한다.

- 라이트 모드 기준. 무채색 + 포인트 1가지(할인/강조용 레드)
- 미니멀 이커머스 — 상품이 주인공이고 UI는 비켜선다
- Primary 액션은 검정 배경 + 흰 텍스트 (이커머스 관례, 대비 확보 용이)
- 모든 텍스트/배경 쌍은 **명도 대비 4.5:1 이상**. `tools/check.js` 가 강제한다
